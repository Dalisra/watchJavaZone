## Always Apply

- **Conservative claims:** "10-30x typical" — don't claim more than you can show
- **Human stays conductor:** AI proposes, you decide — always
- **Tidy as you go:** capture learning NOW (5 sec) not later (2 hours)
- **Skill it when you repeat it:** if you explained something to Claude twice, write a skill
- **Trust but verify:** never ship AI-generated code without running tests
